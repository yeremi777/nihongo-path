## Tujuan

Di akhir pelajaran ini, kamu bisa mengenali kosakata dasar untuk 丁寧な話し方, 尊敬語, dan 謙譲語. Fokusnya bukan menguasai semua keigo, tetapi membaca kata-kata penting yang sering muncul di toko, restoran, kantor, atau percakapan formal.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> 尊敬語 menaikkan pihak lawan bicara, sedangkan 謙譲語 merendahkan sisi pembicara untuk menunjukkan hormat.
</div>

### Ide Dasar

| 丁寧な | ていねいな | sopan/teliti/rapi; di sini fokus pada bahasa sopan. |
| 丁寧な話し方 | ていねいなはなしかた | cara bicara yang sopan. |

Peta keigo hari ini terbagi dua arah: saat membicarakan tindakan orang lain, gunakan bentuk 尊敬語 seperti ご覧になる dan 召し上がる. Saat membicarakan tindakan diri sendiri dengan sopan, gunakan 謙譲語 seperti 申す, 伺う, 拝見する, dan 頂く.

## Catatan Pemakaian

### 尊敬語

- ご覧になる: orang lain melihat.
- おっしゃる: orang lain berkata.
- 召し上がる: orang lain makan/minum.

### 謙譲語

- 申す: saya berkata/bernama.
- 伺う: saya bertanya/mendengar/berkunjung.
- 拝見する: saya melihat sesuatu milik/terkait pihak lain.
- 頂く: saya menerima/makan/minum dengan rendah hati.

## Pola yang Sering Muncul

| Pola | Arti praktis | Contoh konteks |
|---|---|---|
| （Person）がご覧になる | orang terhormat melihat | 先生がご覧になる |
| （Person）がおっしゃる | orang terhormat berkata | 社長がおっしゃる |
| （Person）が召し上がる | orang terhormat makan/minum | お客様が召し上がる |
| （Speaker）が申す | saya berkata/bernama | 田中と申します |
| （Place）へ伺う | saya berkunjung ke tempat | 会社へ伺う |
| （N）を拝見する | saya melihat （N） dengan rendah hati | 資料を拝見する |
| こちらでお召し上がりですか | makan di sini? | restoran/kafe |

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| 尊敬語 / 謙譲語 | 尊敬語 untuk tindakan pihak lain. 謙譲語 untuk tindakan diri sendiri/sisi sendiri. |
| ご覧になる / 拝見する | ご覧になる untuk orang lain melihat. 拝見する untuk saya melihat dengan rendah hati. |
| おっしゃる / 申す | おっしゃる untuk orang lain berkata. 申す untuk saya berkata/bernama. |
| 召し上がる / 頂く | 召し上がる untuk orang lain makan/minum. 頂く untuk saya menerima/makan/minum. |
| お持ち帰り / 持って帰る | お持ち帰り adalah ungkapan toko/restoran. 持って帰る adalah bentuk biasa. |

## Kesalahan Umum

Jangan memakai bentuk rendah hati untuk tindakan lawan bicara. Misalnya, untuk "apakah Anda melihat?", gunakan ご覧になりますか, bukan 拝見しますか.

Di restoran, こちらでお召し上がりですか adalah pertanyaan kepada pelanggan, jadi bentuk hormat 召し上がる dipakai untuk aksi pelanggan.
