## Tujuan

Di akhir pelajaran ini, kamu bisa menyatakan tujuan, perubahan kemampuan, kebiasaan yang diusahakan, dan kesan dari keadaan yang terlihat.

Kamu juga akan membedakan pola yang mirip supaya pilihan jawaban tidak hanya bergantung pada terjemahan bahasa Indonesia.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> baca fungsi kalimatnya dulu. Setelah itu cek partikel, bentuk verba, dan nuansa yang membuat satu pola lebih tepat daripada pola lain.
</div>

Pola hari ini sama-sama dipakai untuk **tujuan dan kebiasaan**, tetapi petunjuknya berbeda. Perhatikan partikel, bentuk negatif/lampau, bentuk kamus, dan siapa yang menjadi fokus kalimat.

## Cara Membentuk Pola

Simbol utama: （N） berarti nomina, （V） berarti verba, （Klausa） berarti klausa, （いAdj） berarti kata sifat-i, dan （なAdj） berarti kata sifat-na.

| Pola | Bentuk dasar | Catatan bentuk |
|---|---|---|
| 〜ために | （V辞書形） + ために / （N） + のために | dipakai untuk untuk; demi tujuan ~. |
| 〜ため（に） | （V普通形） + ために / （N） + のために | dipakai untuk karena; disebabkan oleh ~. |
| 〜ように | （V辞書形） / （Vない形） / （V）可能形 + ように | dipakai untuk agar; supaya ~. |
| 〜ようになる | （V辞書形） / （Vない形） / （V）可能形 + ようになる | dipakai untuk menjadi bisa; mulai menjadi ~. |
| 〜ようにする | （V辞書形） / （Vない形） + ようにする | dipakai untuk berusaha agar; membiasakan untuk ~. |

## Catatan Pemakaian

### 〜ために

Gunakan pola ini untuk **untuk; demi tujuan ~**. Bentuk dasarnya: （V辞書形） + ために / （N） + のために.

Catatan praktis: Dipakai dengan intentional actions dan clear goals.

Contoh inti: 会議に出席するために、東京へ行きました。

### 〜ため（に）

Gunakan pola ini untuk **karena; disebabkan oleh ~**. Bentuk dasarnya: （V普通形） + ために / （N） + のために.

Catatan praktis: Penggunaan sebab/alasan. Sering lebih formal daripada から atau ので.

Contoh inti: 台風のため、飛行機が遅れました。

### 〜ように

Gunakan pola ini untuk **agar; supaya ~**. Bentuk dasarnya: （V辞書形） / （Vない形） / （V）可能形 + ように.

Catatan praktis: Dipakai untuk keadaan target, kemampuan, atau pencegahan.

Contoh inti: 習ったことを忘れないように、復習しましょう。

### 〜ようになる

Gunakan pola ini untuk **menjadi bisa; mulai menjadi ~**. Bentuk dasarnya: （V辞書形） / （Vない形） / （V）可能形 + ようになる.

Catatan praktis: menunjukkan perubahan menjadi kemampuan, kebiasaan, atau keadaan baru.

Contoh inti: 日本語が上手に話せるようになりたいです。

### 〜ようにする

Gunakan pola ini untuk **berusaha agar; membiasakan untuk ~**. Bentuk dasarnya: （V辞書形） / （Vない形） + ようにする.

Catatan praktis: menunjukkan conscious effort, personal rule, atau habit.

Contoh inti: 毎食後、歯をみがくようにしています。

### 〜ように言う

Gunakan pola ini untuk **menyuruh / mengatakan agar seseorang ~**. Bentuk dasarnya: （V辞書形） / （Vない形） + ように言う.

Catatan praktis: Indirect command atau instruction.

Contoh inti: 父にお酒を飲まないように言っています。

### 〜ように言われる

Gunakan pola ini untuk **diberitahu / disuruh untuk ~**. Bentuk dasarnya: （V辞書形） / （Vない形） + ように言われる.

Catatan praktis: Passive form of being instructed atau told.

Contoh inti: 母から今日は早く帰るように言われました。

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| 〜ために / 〜ように | Bedakan dari fungsi utamanya: Tujuan langsung dibanding keadaan/hasil target. Petunjuk pilihan: Gunakan 〜ために untuk tujuan yang disengaja. Gunakan 〜ように untuk kemampuan, keadaan, atau pencegahan. |
| 〜ために / 〜ために | Bedakan dari fungsi utamanya: Tujuan dibanding sebab. Petunjuk pilihan: Gunakan pola pertama saat seseorang bertindak untuk suatu tujuan. Gunakan pola kedua saat sesuatu terjadi karena suatu alasan. |
| 〜ようになる / 〜ようにする | Bedakan dari fungsi utamanya: Perubahan keadaan dibanding usaha sadar. Petunjuk pilihan: Gunakan 〜ようになる saat sesuatu menjadi mungkin/bisa dilakukan. Gunakan 〜ようにする saat seseorang berusaha atau membiasakan diri. |
| 〜ようにする / 〜ことにする | Bedakan dari fungsi utamanya: Ongoing habit/effort dibanding decision. Petunjuk pilihan: Gunakan 〜ようにする untuk repeated effort. Gunakan 〜ことにする untuk a decision. |
| 〜ように言う / 〜ように言われる | Bedakan dari fungsi utamanya: Menyuruh seseorang dibanding disuruh/diberi tahu. Petunjuk pilihan: Gunakan pola pertama dari sisi pemberi instruksi. Gunakan pola kedua dari sisi penerima instruksi. |

## Kesalahan Umum

| Salah | Benar | Kenapa |
|---|---|---|
| 家を買うように、貯金しています。 | 家を買うために、貯金しています。 | Tujuan langsung memakai 〜ために |
| 忘れないために、メモします。 | 忘れないように、メモします。 | Pencegahan/target keadaan memakai 〜ように |
| 日本語が話せるようにしました。 | 日本語が話せるようになりました。 | Perubahan kemampuan memakai 〜ようになる |
| 毎日、歯をみがくようになっています。 | 毎日、歯をみがくようにしています。 | Kebiasaan atau usaha memakai 〜ようにする |
| 母から早く帰るように言いました。 | 母から早く帰るように言われました。 | Instruksi yang diterima memakai 〜ように言われる |

Catatan untuk pembelajar Indonesia: “Untuk” dan “supaya” dalam bahasa Indonesia bisa tumpang tindih, tetapi bahasa Jepang membedakannya. - 〜ために = untuk / demi tujuan langsung - 〜ために = karena / disebabkan oleh - 〜ように = supaya sebuah keadaan tercapai - 〜ようになる = menjadi bisa / berubah menjadi - 〜ようにする = berusaha / membiasakan - 〜ように言われる = disuruh / diberitahu untuk
