## Tujuan

Di akhir pelajaran ini, kamu bisa memakai pola N4 dalam topik **日記を書くようにしましょう。** untuk tujuan dan kebiasaan. Fokusnya adalah memilih partikel, bentuk verba, atau ekspresi yang sesuai dengan konteks kalimat.

Kamu juga akan membedakan pola yang mirip agar tidak menerjemahkan langsung dari bahasa Indonesia tanpa melihat petunjuk bentuk Jepangnya.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> baca fungsi komunikasinya dulu, lalu cek bentuk sebelum dan sesudah pola. Banyak kesalahan N4 muncul karena arti Indonesianya mirip, tetapi partikel atau bentuk akhirnya berbeda.
</div>

Pola hari ini saling terhubung oleh fungsi **tujuan dan kebiasaan**. Gunakan tabel pola sebagai peta cepat: pola yang terlihat mirip biasanya berbeda pada petunjuk seperti partikel, bentuk negatif, bentuk lampau, bentuk kamus, atau sudut pandang pembicara.

## Cara Membentuk Pola

Simbol utama: （N）= nomina, （V）= verba, （Clause）= klausa, （いAdj）= kata sifat-i, dan （なAdj）= kata sifat-na.

| Pola | Bentuk dasar | Catatan bentuk |
|---|---|---|
| 〜ために | （V 辞書形） + ために / （N） + のために | Gunakan bentuk ini untuk untuk; demi tujuan ~. |
| 〜ため（に） | （V 普通形） + ために / （N） + のために | Gunakan bentuk ini untuk karena; disebabkan oleh ~. |
| 〜ように | （V 辞書形） / （V）ない / （V）可能形 + ように | Gunakan bentuk ini untuk agar; supaya ~. |
| 〜ようになる | （V 辞書形） / （V）ない / （V）可能形 + ようになる | Gunakan bentuk ini untuk menjadi bisa; mulai menjadi ~. |
| 〜ようにする | （V 辞書形） / （V）ない + ようにする | Gunakan bentuk ini untuk berusaha agar; membiasakan untuk ~. |
| 〜ように言う | （V 辞書形） / （V）ない + ように言う | Gunakan bentuk ini untuk menyuruh / mengatakan agar seseorang ~. |

## Catatan Pemakaian

### 〜ために

Pola ini dipakai untuk **untuk; demi tujuan ~**. Bentuk intinya adalah （V 辞書形） + ために / （N） + のために.

Catatan praktis: Used dengan intentional actions dan clear goals.

Contoh inti: 会議に出席するために、東京へ行きました。

### 〜ため（に）

Pola ini dipakai untuk **karena; disebabkan oleh ~**. Bentuk intinya adalah （V 普通形） + ために / （N） + のために.

Catatan praktis: Cause/reason usage. Often more formal than から atau ので.

Contoh inti: 台風のため、飛行機が遅れました。

### 〜ように

Pola ini dipakai untuk **agar; supaya ~**. Bentuk intinya adalah （V 辞書形） / （V）ない / （V）可能形 + ように.

Catatan praktis: Used untuk a target state, ability, atau prevention.

Contoh inti: 習ったことを忘れないように、復習しましょう。

### 〜ようになる

Pola ini dipakai untuk **menjadi bisa; mulai menjadi ~**. Bentuk intinya adalah （V 辞書形） / （V）ない / （V）可能形 + ようになる.

Catatan praktis: menunjukkan change into a new ability, habit, atau state.

Contoh inti: 日本語が上手に話せるようになりたいです。

### 〜ようにする

Pola ini dipakai untuk **berusaha agar; membiasakan untuk ~**. Bentuk intinya adalah （V 辞書形） / （V）ない + ようにする.

Catatan praktis: menunjukkan conscious effort, personal rule, atau habit.

Contoh inti: 毎食後、歯をみがくようにしています。

### 〜ように言う

Pola ini dipakai untuk **menyuruh / mengatakan agar seseorang ~**. Bentuk intinya adalah （V 辞書形） / （V）ない + ように言う.

Catatan praktis: Indirect command atau instruction.

Contoh inti: 父にお酒を飲まないように言っています。

### 〜ように言われる

Pola ini dipakai untuk **diberitahu / disuruh untuk ~**. Bentuk intinya adalah （V 辞書形） / （V）ない + ように言われる.

Catatan praktis: Passive form of being instructed atau told.

Contoh inti: 母から今日は早く帰るように言われました。

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| 〜ために / 〜ように | Bedakan dari fungsi utamanya: Direct purpose dibanding state/result goal. Petunjuk pilihan: Gunakan 〜ために untuk an intentional goal. gunakan 〜ように untuk ability, state, atau prevention.. |
| 〜ために / 〜ために | Bedakan dari fungsi utamanya: Purpose dibanding cause. Petunjuk pilihan: Gunakan g218 saat someone acts untuk a goal. gunakan g219 saat something happens because of a reason.. |
| 〜ようになる / 〜ようにする | Bedakan dari fungsi utamanya: Change of state dibanding conscious effort. Petunjuk pilihan: Gunakan 〜ようになる saat something becomes possible. gunakan 〜ようにする saat someone tries atau makes a habit.. |
| 〜ようにする / 〜ことにする | Bedakan dari fungsi utamanya: Ongoing habit/effort dibanding decision. Petunjuk pilihan: Gunakan 〜ようにする untuk repeated effort. gunakan 〜ことにする untuk a decision.. |
| 〜ように言う / 〜ように言われる | Bedakan dari fungsi utamanya: Tell someone dibanding be told. Petunjuk pilihan: Gunakan g223 from the instructor side. gunakan g224 from the receiver side.. |

## Kesalahan Umum

| Salah | Benar | Kenapa |
|---|---|---|
| 家を買うように、貯金しています。 | 家を買うために、貯金しています。 | Direct purpose uses 〜ために |
| 忘れないために、メモします。 | 忘れないように、メモします。 | Prevention/state goal uses 〜ように |
| 日本語が話せるようにしました。 | 日本語が話せるようになりました。 | Ability change uses 〜ようになる |
| 毎日、歯をみがくようになっています。 | 毎日、歯をみがくようにしています。 | Habit/effort uses 〜ようにする |
| 母から早く帰るように言いました。 | 母から早く帰るように言われました。 | Passive instruction uses 〜ように言われる |

Catatan untuk pembelajar Indonesia: Indonesian “untuk” and “supaya” can overlap, but Japanese separates them. - 〜ために = untuk / demi tujuan langsung - 〜ために = karena / disebabkan oleh - 〜ように = supaya sebuah keadaan tercapai - 〜ようになる = menjadi bisa / berubah menjadi - 〜ようにする = berusaha / membiasakan - 〜ように言われる = disuruh / diberitahu untuk
