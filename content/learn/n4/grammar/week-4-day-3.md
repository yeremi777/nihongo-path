## Tujuan

Di akhir pelajaran ini, kamu bisa menyatakan sesuatu yang terlalu berlebihan, mudah atau sulit dilakukan, dan tindakan yang mulai terjadi.

Kamu juga akan membedakan pola yang mirip supaya pilihan jawaban tidak hanya bergantung pada terjemahan bahasa Indonesia.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> baca fungsi kalimatnya dulu. Setelah itu cek partikel, bentuk verba, dan nuansa yang membuat satu pola lebih tepat daripada pola lain.
</div>

Pola hari ini sama-sama dipakai untuk **terlalu, mudah, sulit**, tetapi petunjuknya berbeda. Perhatikan partikel, bentuk negatif/lampau, bentuk kamus, dan siapa yang menjadi fokus kalimat.

## Cara Membentuk Pola

Simbol utama: （N） berarti nomina, （V） berarti verba, （Klausa） berarti klausa, （いAdj） berarti kata sifat-i, dan （なAdj） berarti kata sifat-na.

| Pola | Bentuk dasar | Catatan bentuk |
|---|---|---|
| 〜すぎる | （Vますstem） + すぎる / （いAdj）-stem + すぎる / （なAdj） + すぎる | dipakai untuk terlalu ~. |
| 〜やすい | （Vますstem） + やすい | dipakai untuk mudah untuk ~; cenderung ~. |
| 〜にくい | （Vますstem） + にくい | dipakai untuk sulit untuk ~. |
| 〜出す | （Vますstem） + 出す | dipakai untuk mulai ~ secara tiba-tiba. |
| 〜終わる | （Vますstem） + 終わる | dipakai untuk selesai melakukan ~. |
| 〜続ける | （Vますstem） + 続ける | dipakai untuk terus melakukan ~. |

## Catatan Pemakaian

### 〜すぎる

Gunakan pola ini untuk **terlalu ~**. Bentuk dasarnya: （Vますstem） + すぎる / （いAdj）-stem + すぎる / （なAdj） + すぎる.

Catatan praktis: menunjukkan an excessive tingkat dan often berarti not appropriate.

Contoh inti: この帽子は小さすぎます。

### 〜やすい

Gunakan pola ini untuk **mudah untuk ~; cenderung ~**. Bentuk dasarnya: （Vますstem） + やすい.

Catatan praktis: menunjukkan bahwa tindakan mudah dilakukan atau sesuatu mudah terjadi.

Contoh inti: このペンは書きやすいです。

### 〜にくい

Gunakan pola ini untuk **sulit untuk ~**. Bentuk dasarnya: （Vますstem） + にくい.

Catatan praktis: Opposite of 〜やすい. menunjukkan difficulty atau resistance.

Contoh inti: この地図はわかりにくいです。

### 〜出す

Gunakan pola ini untuk **mulai ~ secara tiba-tiba**. Bentuk dasarnya: （Vますstem） + 出す.

Catatan praktis: Sering dipakai saat sesuatu mulai terjadi secara tiba-tiba atau tidak terduga.

Contoh inti: 赤ちゃんが急に泣き出しました。

### 〜終わる

Gunakan pola ini untuk **selesai melakukan ~**. Bentuk dasarnya: （Vますstem） + 終わる.

Catatan praktis: menunjukkan penyelesaian tindakan dari awal sampai akhir.

Contoh inti: ご飯を食べ終わりました。

### 〜続ける

Gunakan pola ini untuk **terus melakukan ~**. Bentuk dasarnya: （Vますstem） + 続ける.

Catatan praktis: menunjukkan tindakan yang terus berlangsung selama waktu tertentu.

Contoh inti: 一週間、この薬を飲み続けてください。

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| 〜すぎる / とても | Bedakan dari fungsi utamanya: Excessive dibanding simply very. Petunjuk pilihan: Gunakan 〜すぎる saat the tingkat is too much. Gunakan とても untuk neutral “very.”. |
| 〜やすい / 〜にくい | Bedakan dari fungsi utamanya: Mudah dibanding sulit. Petunjuk pilihan: Gunakan 〜やすい untuk tindakan mudah. Gunakan 〜にくい untuk tindakan sulit. |
| 〜出す / 〜始める | Bedakan dari fungsi utamanya: Mulai tiba-tiba dibanding mulai netral. Petunjuk pilihan: Gunakan 〜出す untuk awal yang tiba-tiba/tidak terduga. Gunakan 〜始める untuk awal yang biasa. |
| 〜終わる / 〜続ける | Bedakan dari fungsi utamanya: Finish doing dibanding continue doing. Petunjuk pilihan: Gunakan 〜終わる untuk completion. Gunakan 〜続ける untuk continuation. |

## Kesalahan Umum

| Salah | Benar | Kenapa |
|---|---|---|
| この帽子は小さいすぎます。 | この帽子は小さすぎます。 | Kata sifat-i membuang い sebelum 〜すぎる |
| このペンは書くやすいです。 | このペンは書きやすいです。 | Gunakan bentuk sebelum ます sebelum 〜やすい |
| ご飯を食べる終わりました。 | ご飯を食べ終わりました。 | Gunakan bentuk sebelum ます sebelum 〜終わる |

Catatan untuk pembelajar Indonesia: Untuk pembelajar Indonesia, anggap bentuk sebelum ます sebagai “bentuk penghubung” untuk pola-pola ini. 飲みます → 飲みすぎる 書きます → 書きやすい 読みます → 読みにくい 泣きます → 泣き出す 食べます → 食べ終わる 飲みます → 飲み続ける
