# 〜わけではない

## Goal

Understand how `〜わけではない` softens a denial and means "it is not that..." or "not necessarily."

## Pattern

```txt
Plain form + わけではない
Noun + な + わけではない
な-adjective + な + わけではない
```

## Core Meaning

`〜わけではない` denies a conclusion without rejecting everything completely.

## English Explanation

Use this pattern when you want to say that something is not completely true, or when you want to correct an assumption gently.

## Indonesian Explanation

Gunakan pola ini untuk menyangkal kesimpulan secara tidak mutlak.

Artinya mirip dengan "bukan berarti..." atau "tidak selalu..."

## How to Use

```txt
嫌いなわけではない。
```

This does not mean "I like it." It means "It is not that I dislike it."

## Examples

### Example 1

```txt
日本語が難しくないわけではありません。
```

**English:** It is not that Japanese is not difficult.

**Indonesian:** Bukan berarti bahasa Jepang tidak sulit.

### Example 2

```txt
忙しいわけではないけれど、今日は早く帰りたいです。
```

**English:** It is not that I am busy, but I want to go home early today.

**Indonesian:** Bukan berarti saya sibuk, tetapi hari ini saya ingin pulang cepat.

## Nuance

This pattern is useful when the speaker wants to be careful, indirect, or more precise.

## Common Mistake

Do not treat `〜わけではない` as a simple strong negative.

It usually leaves room for a more nuanced meaning.

## Mini Practice

Translate these sentences:

1. It is not that I hate kanji.
2. It is not necessarily easy.
3. It is not that I do not understand.
