# 〜てしまう

## Goal

Understand how `〜てしまう` is used to show that an action is completed, accidental, or emotionally regrettable.

## Pattern

```txt
Verb て-form + しまう
Verb て-form + しまった
Verb て-form + しまいました
```

## Core Meaning

`〜てしまう` has two common meanings:

1. Something is done completely.
2. Something happened and the speaker feels regret, disappointment, or surprise.

## English Explanation

Use `〜てしまう` when an action is finished completely, or when something happened in a way that feels unfortunate.

It often adds emotional nuance.

## Indonesian Explanation

Gunakan `〜てしまう` ketika suatu tindakan sudah selesai sepenuhnya, atau ketika sesuatu terjadi dan pembicara merasa menyesal, kecewa, atau tidak sengaja melakukannya.

Pola ini sering menambahkan nuansa perasaan.

## How to Use

Attach `しまう` to the て-form of a verb.

```txt
Verb て-form + しまう
```

Use the past form `しまった` or polite past `しまいました` when the action already happened.

## Examples

### Example 1

```txt
宿題を全部やってしまいました。
```

**English:** I finished all of my homework.

**Indonesian:** Saya sudah menyelesaikan semua PR.

This sentence focuses on completion.

### Example 2

```txt
財布を忘れてしまいました。
```

**English:** I unfortunately forgot my wallet.

**Indonesian:** Saya lupa membawa dompet.

This sentence has a feeling of regret.

### Example 3

```txt
大切なファイルを消してしまった。
```

**English:** I accidentally deleted an important file.

**Indonesian:** Saya tidak sengaja menghapus file penting.

This sentence shows an accidental action with regret.

## Nuance

Without `しまう`, the sentence sounds more neutral.

```txt
財布を忘れました。
```

This simply means:

**English:** I forgot my wallet.

**Indonesian:** Saya lupa membawa dompet.

But:

```txt
財布を忘れてしまいました。
```

adds the feeling of:

```txt
Oh no, I forgot my wallet.
```

## Common Mistake

Do not always translate `〜てしまう` as "finish."

Sometimes the main meaning is not completion, but regret or accidental result.

## Mini Practice

Translate these sentences:

1. I accidentally broke my phone.
2. I finished reading the book.
3. I unfortunately lost my ticket.
