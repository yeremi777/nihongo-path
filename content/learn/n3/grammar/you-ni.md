# 〜ように

## Goal

Understand how `〜ように` is used to describe a goal, purpose, or desired result.

## Pattern

```txt
Verb dictionary form + ように
Verb ない-form + ように
Potential verb + ように
```

## Core Meaning

`〜ように` often means "so that" or "in order to" when the speaker wants a certain state or result to become possible.

## English Explanation

Use `〜ように` when the focus is on reaching a condition, ability, or state.

It is common with potential verbs, negative verbs, and verbs that describe states rather than direct actions.

## Indonesian Explanation

Gunakan `〜ように` untuk menyatakan tujuan atau keadaan yang ingin dicapai.

Pola ini sering dipakai dengan kata kerja potensial, bentuk negatif, atau situasi yang tidak sepenuhnya bisa dikontrol langsung.

## How to Use

```txt
日本語が話せるように、毎日練習しています。
```

The goal is the state of being able to speak Japanese.

## Examples

### Example 1

```txt
漢字を忘れないように、毎日復習します。
```

**English:** I review every day so that I do not forget kanji.

**Indonesian:** Saya mengulang setiap hari supaya tidak lupa kanji.

### Example 2

```txt
試験に合格できるように、文法を勉強しています。
```

**English:** I am studying grammar so that I can pass the exam.

**Indonesian:** Saya belajar tata bahasa supaya bisa lulus ujian.

## Nuance

`〜ために` often marks a more direct purpose. `〜ように` often points toward a condition or ability the speaker wants to achieve.

## Common Mistake

Do not use `〜ように` only because the English sentence says "to."

For direct intentional actions, `〜ために` may be more natural.

## Mini Practice

Translate these sentences:

1. I speak slowly so that everyone can understand.
2. I set an alarm so that I will not be late.
3. I practice kanji so that I can read articles.
