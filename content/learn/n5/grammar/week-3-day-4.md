## Tujuan

Mengenali pola dasar untuk ketika ~; saat ~, sebelum ~, setelah ~, pergi/datang/pulang untuk tujuan.

Di akhir pelajaran ini, kamu bisa membaca kalimat seperti わたしは子どものとき、フランスに住んでいました, じゅぎょうの前に、よしゅうをしましょう, おふろに入ったあとで、ビールを飲みます. Fokusnya adalah melihat bentuk kecil yang menjadi petunjuk arti.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> baca pola dari kiri ke kanan. Tandai partikel, bentuk verba, atau kata penghubung sebelum menebak arti seluruh kalimat.
</div>

## Cara Membentuk Pola

Simbol utama: （N）= nomina, （V）= verba, （Adj）= kata sifat, （Place）= tempat, （Person）= orang, dan （Time）= waktu.

| Pola | Bentuk dasar | Catatan bentuk |
|---|---|---|
| 〜とき | （N）のとき／（いAdj）とき／（なAdj）なとき／（V）普通形とき | Describes the time or situation when something happens |
| 〜前に | （N）の前に／（V辞書形） + 前に | Used for doing something before a noun event or before doing a verb action |
| 〜あとで | （N）のあとで／（Vた） + あとで | Used for doing something after a noun event or after finishing a verb action |
| 〜に行く・来る・帰る | （N）に／（Vます-stem）に + 行く／来る／帰る | に marks the purpose of movement |

## Catatan Pemakaian

- Ketika ~: Describes the time or situation when something happens. （Vる）とき often means before or around doing. （Vた）とき often means after the action happened.
- Sebelum ~: Used for doing something before a noun event or before doing a verb action. The verb before 前に uses dictionary form.
- Setelah ~: Used for doing something after a noun event or after finishing a verb action. The verb before あとで uses past form.
- Pergi/datang/pulang untuk tujuan: に marks the purpose of movement. With verbs, use the ます-stem before に.

Indonesian “waktu” can map to several Japanese patterns:

- 〜とき = when / saat
- 〜前に = before / sebelum
- 〜あとで = after / setelah

For 前に and あとで, verb form is the key:

- （Vる）前に = before doing
- （Vた）あとで = after doing

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| （Vる）とき / （Vた）とき | When/before doing vs when/after doing. Use （V）るとき before or while doing. Use （V）たとき after the action happened. |
| （N）の前に / （Vる）前に | Before a noun event vs before a verb action. Use の after nouns. Use dictionary form before 前に. |
| （N）のあとで / （Vた）あとで | After a noun event vs after a verb action. Use の after nouns. Use past form before あとで. |
| 前に / あとで | Before vs after. Use 前に for preparation before an action. Use あとで after an action is finished. |
| （Vます-stem）に行く / （Place）に行く | Purpose vs destination. Use （V）ます-stemに for the purpose. Use （Place）+に/へ for destination. |

## Kesalahan Umum

| Titik salah | Kurang tepat | Lebih tepat | Petunjuk |
|---|---|---|---|
| Before doing uses dictionary form | 家を出た前に、メールします。 | 家を出る前に、メールします。 | Saya akan mengirim email sebelum keluar rumah. |
| After doing uses past form | ごはんを食べるあとで、歯をみがきます。 | ごはんを食べたあとで、歯をみがきます。 | Saya menggosok gigi setelah makan. |
| Purpose movement uses （Vます-stem） + に | としょかんへ本を返し行きました。 | としょかんへ本を返しに行きました。 | Saya pergi ke perpustakaan untuk mengembalikan buku. |
