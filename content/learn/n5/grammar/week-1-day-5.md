## Tujuan

Mengenali pola dasar untuk atau; penanda pilihan, seperti ~ dan lainnya, dari ~ sampai ~, sekitar waktu.

Di akhir pelajaran ini, kamu bisa membaca kalimat seperti 毎朝、コーヒーか紅茶を飲みます, 駅の前にコンビニや銀行などがあります, 家から学校まで1時間かかります. Fokusnya adalah melihat bentuk kecil yang menjadi petunjuk arti.

<div class="lesson-callout">
  <strong>Fokus hari ini:</strong> baca pola dari kiri ke kanan. Tandai partikel, bentuk verba, atau kata penghubung sebelum menebak arti seluruh kalimat.
</div>

## Cara Membentuk Pola

Simbol utama: （N）= nomina, （V）= verba, （Adj）= kata sifat, （Place）= tempat, （Person）= orang, dan （Time）= waktu.

| Pola | Bentuk dasar | Catatan bentuk |
|---|---|---|
| 〜か | （N1）か（N2） | Used between two choices |
| 〜や〜など | （N1）や（N2）など | Lists examples, not a complete list |
| 〜から〜まで | （N1）から + （N2）まで | N1 and N2 can be places or times |
| 〜ごろ | （Time） + ごろ | Used only with time expressions, not prices or general amounts |
| 〜くらい・〜ぐらい | （Amount / period） / degree + くらい／ぐらい | Used with approximate amount, duration, distance, price, or degree |
| 〜だけ | （N） / quantity + だけ | Dipakai untuk arti “hanya” yang netral. |

## Catatan Pemakaian

- Atau: Used between two choices. It can also mark a question at sentence end, but this item focuses on choice.
- Seperti ~ dan lainnya: Lists examples, not a complete list. など means “and so on.”
- Dari ~ sampai ~: N1 and N2 can be places or times. Shows start and end points.
- Sekitar waktu: Used only with time expressions, not prices or general amounts.
- Kira-kira: Used with approximate amount, duration, distance, price, or degree. くらい and ぐらい are both common.
- Hanya: だけ berarti “hanya” secara netral. Bisa menempel pada nomina, jumlah, periode waktu, dan beberapa partikel.

Indonesian “sekitar” can become ごろ or ぐらい in Japanese:

- ごろ = around a time, like 7時ごろ
- くらい／ぐらい = about an amount, duration, price, distance, or degree

## Hal yang Mudah Tertukar

| Pasangan | Cara membedakan |
|---|---|
| 〜か / 〜や〜など | Choice between alternatives vs example list. Use か for “A or B.” Use や〜など for “A, B, and things like that.” |
| 〜から〜まで / 〜まで only | Start-to-end vs endpoint only. Use から〜まで when both start and end are stated. Use まで when only the end point matters. |
| 〜ごろ / 〜くらい・〜ぐらい | Approximate clock time vs approximate amount/degree. Use ごろ for 7時ごろ. Use ぐらい for 1時間ぐらい, 1,000円ぐらい. |
| 〜だけ / 〜しか〜ない | Neutral only vs restrictive only with negative. Use だけ for neutral “only.” Use しか〜ない later when stressing limitation. |
| Particle + は（pola ini note） / Plain particle | Topic or emphasis after particles. Use は after に, で, へ, まで when the particle phrase is contrasted or emphasized. |

## Kesalahan Umum

| Titik salah | Kurang tepat | Lebih tepat | Petunjuk |
|---|---|---|---|
| Choice marker か | コーヒーや紅茶を飲みます。 | コーヒーか紅茶を飲みます。 | Saya minum kopi atau teh hitam. |
| Example list uses や〜など | 駅の前にコンビニか銀行などがあります。 | 駅の前にコンビニや銀行などがあります。 | Di depan stasiun ada hal-hal seperti minimarket dan bank. |
| Approximate time uses ごろ | 7時ぐらい電話します。 | 7時ごろ電話します。 | Saya akan menelepon sekitar jam 7. |
| Approximate amount uses くらい／ぐらい | タクシーで1,000円ごろかかります。 | タクシーで1,000円ぐらいかかります。 | Biayanya sekitar 1.000 yen naik taksi. |
